# Invitations

Party invitation pages with RSVP. Each party lives in its own folder.

- `wine-tasting/` — Ladies' Wine Tasting, Dec 10, 2026
- `demo/` — sample invitation for the storefront (made-up party; nothing is saved)
- `invites/` — storefront page for made-to-order invitations (edit SETTINGS at the bottom for the order link and price)

To make a new one: copy a folder, edit the `EVENT` settings block at the bottom of `index.html`, create a new Google Form and paste its form action and `entry.*` ids.
